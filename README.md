# DataScope

時系列データと横断面データの違いを、**同じ数値をスライダーで切り替えながら**体験的に学ぶ教材アプリです。

- **学ぶ** — 2つのデータの考え方と、時系列データの活用フロー（発見→分析→予測）
- **データを見る** — 売上データをスライダーで「時系列（折れ線）」⇄「横断面（棒グラフ）」に連続的に変形させる、このアプリの中心機能
- **クイズ** — 「これはどっち？」形式の全6問
- **学習記録** — 正答率・回答数をブラウザに保存

Vite + TypeScript + Canvas 2D のみで作られており、外部チャートライブラリには依存していません。

## 開発環境で動かす

```bash
npm install
npm run dev
```

`http://localhost:5173` が開きます。

## 本番ビルド

```bash
npm run build   # dist/ に出力
npm run preview # ビルド結果をローカルで確認
```

## プロジェクト構成

```
src/
  data.ts    サンプルデータ（月別×商品別の売上）
  chart.ts   Canvas 2D で折れ線⇄棒グラフを補間描画するクラス
  quiz.ts    クイズの設問データ
  main.ts    タブ切り替えとUIの組み立て
  style.css  デザイントークン（色・タイポグラフィ）
```
